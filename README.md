# Al-Mursyidul Amin — Prototype Website

Prototype pusat informasi digital Pondok Pesantren Al-Mursyidul Amin.

## Isi
- Sejarah, pendiri, dan pimpinan
- Cabang Gambut, Bati-Bati, dan Sungai Andai
- Pendidikan dan kehidupan santri
- Filter Cabang / Tahun / Putra-Putri
- Data & arsip tahunan
- Struktur pondok Putra dan Putri untuk seluruh bidang
- Arsip guru dan organisasi santri
- Nahdatul Mutaalimin / Mutaalimat
- Unit usaha dan media
- PSB
- Transparansi sumber dan status verifikasi
